## PRACTICE PROBLEM 3


### 3.A
ISPC's foreach and Cilk's cilk_spawn both expose operations that may execute concurrently. In the example, the programmer
must not rely on the loop iterations completing in sequential order. Each assignment or spawned call may overlap with 
other iterations.

Their implementations are different. ISPC maps several program instances to the SIMD lanes of a CPU core, so multiple
iterations execute together using vector instructions, typically in lockstep with masks for divergent control flow.

Cilk instead creates logical tasks that are scheduled into workers threads, usually across multiple CPU cores using work
stealing. Each Cilk task normally executes as separate scalar execution context rather than as a SIMD lane.


### 3.B
Cilk specifies that spawned function may execute in parallel with the caller, but it does not require it.
This gives the runtime scheduler the freedom to choose the best execution strategy based on the available
hardware and system load. For example, the scheduler may execute the function immediately, delay it, or runs
it sequentially if there are not enough available cores. This flexibility enables optimizations such as work 
stealing and allows the same program to scale efficiently across machines with different numbers of core.

### 3.C

The cache line size 4bytrs, which is the size of the one float, so every element of A occupies a separate 
cache line. the 32KB cache can hold only 8102 elements, while A contains 65536 elements and occupies 256 KB.

The program sequentially scans the entire array. Between two accesses to the same element, it accesses 65635 other cache
lanes, which is far more than the 8192 lines the cache can hold. Therefore, each element is evicted before it is accessed
again. As a result, every access to A is a cache miss, even after the first repetition.

### 8.B

When every instruction depends on the previous one, the next instruction cannot begin until the previous instruction 
complete its WB stage. As a result, the pipeline cannot overlap instruction execution and remains mostly idle.

Each instruction requires 4 clock cycles to complete, so one instruction finishes every 4 clock cycles. 
```Throughput = 1/4 instruction per clock (0.25 IPS)```
